# Streaming-Content-Trends
Data analytics project exploring streaming content trends, ratings, popularity, languages, and release years using Tableau.
Streaming Content Trends Dashboard
Project Overview
This project explores streaming content trends using data analysis and visualization. It examines movies and TV shows, release years, popularity, audience ratings, languages, genres, and countries of origin.
Tools Used
Microsoft Excel: Data cleaning and analysis.
Tableau Public: Data visualization and dashboard development.
Key Areas of Analysis
Movies vs. TV shows
Content distribution by release year
Search categories: Popular, Top Rated, and Trending
Content by country of origin
Original language distribution
Popularity and audience ratings
Project Objectives
Identify patterns in streaming content.
Compare movies and TV shows.
Explore content popularity and ratings.
Present findings through visualizations.
Skills Demonstrated
Data cleaning, exploratory data analysis, Excel formulas, data visualization, dashboard design, and data storytelling.
